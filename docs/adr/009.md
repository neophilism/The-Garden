# ADR-009: Optional read-only evidence-bound AI

Status: proposed planning decision; verify integration-specific assumptions at implementation.

## Decision

Assistant tools retrieve only authorized records and generate cited, uncertain answers; no publication, messaging, enrollment or financial mutation. Keep ordinary search independent.

## Rationale

Reduces the impact of prompt injection and hallucinated history. Source text is untrusted data, never tool authority.

## Review trigger and limits

Enable only after provider/privacy/cost authorization, expert evaluation and independent security testing. Re-evaluate every model/config change.
