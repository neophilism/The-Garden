# ADR-010: Evidence-based progress, not PR-count theater

Status: proposed planning decision; verify integration-specific assumptions at implementation.

## Decision

Track exact PR/check/commit/deployment evidence and separate current scope, conditional scope, scholarly progress and observed health. Freeze relative weights per baseline.

## Rationale

Merged code may fail online; split PRs must not manufacture progress. Unknown is not green.

## Review trigger and limits

Adapt to Engine Room actual schema without changing semantics; preserve denominator history and reopened/regressed work.
