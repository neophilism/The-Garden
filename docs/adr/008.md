# ADR-008: Provider contracts before reuse or integration claims

Status: proposed planning decision; verify integration-specific assumptions at implementation.

## Decision

Prefer existing authorized identity/security/Engine Room engines. Pin real API contracts and consumer tests; retain a clearly proposed intermediate format until discovery succeeds.

## Rationale

Prevents duplicate products and fabricated integrations. Failure of progress synchronization must not interrupt public reading.

## Review trigger and limits

Review when actual contracts are available; record incompatibilities and migrations rather than quietly substituting a different service.
