# ADR-004: PostgreSQL source of application truth with bounded search

Status: proposed planning decision; verify integration-specific assumptions at implementation.

## Decision

Use authorized Neon PostgreSQL for application records and transactional jobs. Start with PostgreSQL text/trigram and structured querying behind adapters; benchmark before adding a separate paid search cluster.

## Rationale

Avoid unnecessary providers and cross-store consistency until measured scale justifies them. Separate public/restricted indexes and permission-first retrieval are mandatory.

## Review trigger and limits

Verify extension availability and current supported versions. Introduce specialized search only with documented relevance/latency need, migration plan and cost authorization.
