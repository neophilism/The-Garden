# The Garden

The Garden is a public-information and historical-research platform under development.

This initial commit establishes the default branch of an empty repository so subsequent work can be proposed, tested, and integrated through pull requests. It is not an implemented or deployed application.

The owner-approved development baseline is `GARDEN-WEB-PLAN-001` (10 October 2026): 210 planned work items, comprising 196 public/research items and 14 conditional governmental items. Those identifiers are not GitHub pull-request numbers. The full specification and source-accountable handoff are being imported; do not infer completion from this initialization.

No credentials, private research corpus, licensed archival imagery, or personal records belong in this public repository. No license to third-party research materials is granted.
